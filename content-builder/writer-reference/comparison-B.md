# Comparison B — MCF3M vertex form rewrite

## 1. Opening

A basketball leaves your hand and arcs toward the net. If you know the highest point of that arc, you can describe the whole flight. The same is true for any parabola: once you know the vertex, you know where the curve turns and whether it opens up or down.

Vertex form makes the vertex easy to read. A quadratic written as

\[f(x) = a(x - h)^2 + k\]

places the vertex at the point \((h, k)\). The value of \(a\) controls direction: positive opens up, negative opens down.

Before we work through examples, test your reading.

**Prediction:** Look at \(f(x) = (x + 3)^2 + 1\). The equation is written in vertex form, but notice the sign inside the bracket. Where is the vertex? Write down its coordinates before moving on.

## 2. Worked example

**Equation:** \(y = -3(x + 2)^2 + 4\)

**Reading the vertex**

Compare the equation to the general form \(y = a(x - h)^2 + k\).

- The bracket contains \((x + 2)\). Since vertex form uses \((x - h)\), we rewrite \(x + 2\) as \(x - (-2)\). So \(h = -2\).
- The constant outside the bracket is \(+4\), so \(k = 4\).

The vertex is \((-2, 4)\).

**Maximum or minimum?**

The coefficient in front of the bracket is \(-3\). Because \(a\) is negative, the parabola opens downward. A downward-opening parabola has a highest point, so the vertex is a **maximum**.

The maximum value of the function is \(4\), and it occurs when \(x = -2\).
