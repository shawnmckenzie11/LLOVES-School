LLOVES uses the same Web OAuth client pattern as the Cannabis Paper Scraper: a Google Cloud Web application client, External consent screen, personal Google accounts. Mock email login is tests-only.

  1. Open Google Cloud → APIs & Services → Credentials in the McKenzian project.
  2. Create (or reuse) an OAuth client of type Web application.
  3. Add authorized JavaScript origin http://127.0.0.1:8787 and redirect URI {{ redirect_uri }}.
  4. Copy client id and secret into lms/.env (see lms/GOOGLE.md).
  5. Restart python3 lms/app.py and open http://127.0.0.1:8787 (not localhost, unless you also added that origin).

IT email solutions@mckenzian.com must be a Test user while the consent screen is in Testing. Staff Gmail addresses are allowlisted in LLOVES after you register them — Google will still show the account picker.
