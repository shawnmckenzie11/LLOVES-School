## Team challenge (student-facing)

Start with \(y = x^2\). Using a vertical stretch or compression (\(a \neq 0\)), a reflection in the \(x\)-axis, and translations \(h\) and \(k\), produce **three different** graphs that each pass through \((2, 5)\).

Give each graph as an equation \(y = a(x - h)^2 + k\).

Which parameters are **forced** by the point \((2, 5)\)? Which stay **free**?
