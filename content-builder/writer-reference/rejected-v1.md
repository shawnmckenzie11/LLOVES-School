# Rejected student copy (M4-L1 v1)

Keep these as negative exemplars. Do not reuse the voice.

## Developer notes in the student page

Rejected: “The graph tool is the local board (parabola, vertex marker labelled (h, k), dashed axis of symmetry, live vertex-form equation, the same function expanded as ax^2 + bx + c, and a short table of shared points). It is not a required GeoGebra page.”

Why: engine, integration, and fallback policy. The student needed a task: set this graph to match this equation; then say what the vertex marker shows.

## Itinerary narration

Rejected: “First you will follow a worked reading of one vertex-form equation. Then you will use the graph tool… After that, two practice questions…”

Why: timetable, not a next action.

## Licence essay inside the example

Rejected: “Worked reading (OpenStax College Algebra 2e, §5.1, Figure 5 paragraph, CC BY-NC-SA 4.0).”

Why: attribution belongs in credits. The example should read the equation.

## Prerequisite as the hook

Rejected: “You already know how stretching, flipping, and sliding change the graph of y = x^2. This lesson is about reading a quadratic written in vertex form.”

Why: no reason to care. A hook asks them to predict or notice something.

## Field names as teaching

Rejected: paragraphs that start “Prediction.” “Action.” “Interpretation.” as labels.

Why: those are spec fields. Students get a question, then a move, then a check.
