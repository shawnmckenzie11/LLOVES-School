        Quit without saving?

        Nothing from this class will be saved, including attendance, participation and the catch-up code. This can't be undone.

        What's a test class?

        A test class works just like a real one. Students can join, take attendance, answer questions and use the catch-up code. Everything is kept separate from your real classes, so it never counts toward marks, participation or module totals, and it won't change your class deck.

        Test classes appear in Lesson Slides with a TEST tag. Delete one from its ⋯ menu to remove everything recorded in it, and its catch-up code stops working right away.

        Test class

        This column is from a test class, so it isn't counted in participation, marks or module totals. Delete the test from Lesson Slides to remove it.

        Delete this test class?

        This removes its attendance, answers, catch-up answers and deck copy, and turns off its catch-up code. Your real classes aren't affected. This can't be undone.
