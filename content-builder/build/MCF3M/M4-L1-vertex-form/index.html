Lesson 1: The Vertex Form of a Quadratic Function

Goal Read the turning point and axis from vertex form, and show that expanding to standard form still describes the same curve.

You will need Paper or a notebook, and the graph board on this page.

Look at the water leaving the fountain. Each stream goes up and comes down.

Choose one stream. Mark the highest point of that stream — the place the water does not go above. Do not measure, and do not write an equation yet.

That turning point is the fact we will want from an equation of the curve. Vertex form is the writing that makes the high or low point readable.

A quadratic written as

f(x) = a(x - h)² + k

is in vertex form. The vertex is the point (h, k). The axis of symmetry is the vertical line x = h. The sign of a tells you whether that vertex is a maximum or a minimum: negative a opens downward, so the vertex is a highest point; positive a opens upward, so the vertex is a lowest point.

Look at f(x) = (x + 3)² + 1. The equation is already in vertex form, but notice the sign inside the brackets.

f(x) = (x + 3)² + 1

Where is the vertex? Write its coordinates before you check on the graph.

In this course, f(x) = a(x - h)² + k is vertex form. The expanded writing f(x) = ax² + bx + c is standard form. Some books swap those names; this course does not.

Which writing shows the peak?

Suppose a fountain stream is modelled by either of these two writings. They are meant to be the same curve.

f(x) = -\frac{1}{4}(x - 3)² + 5

and

f(x) = -\frac{1}{4}x² + \frac{3}{2}x + \frac{11}{4}

Without expanding yet: which writing makes it easier to name the highest point of the stream? Write the peak you can read, and say why that writing helped.

Same claim, two ways to check

Alex and Jordan both claim the two writings describe the same fountain arc. They check the claim differently.

Follow both paths. Each should convince you the writings match — and that the peak is at (3, 5).

Path A — expand and compare

Alex works on paper.

Start from the vertex-form writing. Square the binomial: (x - 3)² = x² - 6x + 9.

Multiply by a = -\frac{1}{4}: -\frac{1}{4}x² + \frac{3}{2}x - \frac{9}{4}.

Add k = 5: -\frac{1}{4}x² + \frac{3}{2}x + \frac{11}{4}.

That matches the second writing exactly. Expanding did not invent a new curve.

Path B — table and graph

Jordan builds a short table.

Evaluate both writings at a few inputs. At x = 3, both give 5 — the peak you can already read from vertex form.

At x = 1, both give 4. At x = 5, both give 4. The shared points sit on one downward-opening arc.

On the graph board, those table points land on the same parabola. Matching outputs are another way to see the writings are equivalent.

  3. C When might you still prefer the expanded writing ax² + bx + c, even if the peak is harder to see at a glance?

Read the turning point from the equation

You named a vertex from a plus inside the brackets. Read this next equation the same way — vertex, axis, and whether the turning point is a maximum or a minimum.

Sketch a parabola that opens downward and turns at a point left of the origin and above the x-axis. Label that turning point. Draw a dashed vertical line through it.

The equation of that graph is

y = -3(x + 2)² + 4

We need the vertex, the axis of symmetry, and whether the vertex is a maximum or a minimum.

Compare the equation with y = a(x - h)² + k.

The brackets contain (x + 2). Vertex form uses (x - h), so rewrite x + 2 as x - (-2). That makes h = -2. The constant outside the brackets is +4, so k = 4.

The vertex is (-2, 4). The axis of symmetry is the vertical line through the vertex, x = -2.

The coefficient in front of the brackets is -3. Because a is negative, the parabola opens downward, so the vertex is a maximum. The maximum value of the function is 4, and it occurs when x = -2.

That highest point is the same kind of fact you marked on the water stream, now read from the writing.

A second equation, with nothing added outside

The last equation had a constant outside the brackets, so k was easy to see as a height. This Ontario sample includes

h(x) = -2(x + 1)²

as one of the graphs to read from f(x) = x². Use it here to inspect vertex form. (The sample also names g(x) = x² - 4; stay with h(x).

The brackets contain (x + 1). Rewrite x + 1 as x - (-1), so h = -1. There is no constant added outside, so k = 0. The vertex is (-1, 0), and the axis is x = -1.

The coefficient is -2, so a is negative and the parabola opens downward. The vertex is a maximum even though k = 0. Maximum versus minimum comes from the sign of a, not from whether k looks positive.

Could you have decided maximum versus minimum from k on this equation? Say why or why not.

What this writing is for

You have been reading vertex form. Factored form f(x) = a(x - r)(x - s) makes the x-intercepts easy to see. Standard form f(x) = ax² + bx + c makes the y-intercept easy to see. Vertex form does not make those intercepts as obvious — and the vertex is not an intercept unless it actually sits on an axis.

What can you read from vertex form f(x) = a(x - h)² + k that is harder to see when the same function is written as f(x) = ax² + bx + c? Do not rewrite the function in another form.

Key idea

Vertex form f(x) = a(x - h)² + k makes the vertex (h, k) and the axis x = h readable at a glance. Expanding that writing into ax² + bx + c describes the same parabola — it does not move the curve.

Need to know

  • Match brackets to (x - h). A plus inside the brackets means h is negative.
  • Maximum versus minimum comes from the sign of a, not from the sign of k and not from which quadrant the vertex sits in.
  • a stretches or flips; k moves the vertex up or down. Those jobs are not the same.
  • Two writings are equivalent when expansion matches or when shared table points sit on one graph.
