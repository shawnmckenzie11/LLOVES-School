# Live Lesson Theme & Style Guide  — Agent Info

## STYLE

### Colours
- Primary Blue: `#3A8DC9`
- Charcoal Black: `#201D1D`
- Cool Gray: `#B3B5B9`
- White: `#FFFFFF`

### Typography
- Display: **Barlow Condensed Bold / ExtraBold**
- Body/UI: **Barlow Regular / Medium**

### Design Language
Bold, clean, energetic, modern, educational, Canadian.

- High contrast; Blue is the primary accent.
- Use large, strong headings and generous whitespace.
- Keep layouts simple, crisp, and highly legible.
- Use typography, spacing, and Blue/Gray emphasis to communicate hierarchy.
- Avoid unnecessary colours, gradients, excessive shadows, and decorative elements.
- Design the deck as a **game interface**, not a conventional presentation.

### Core Slide Rule
Every slide should make two things immediately clear:

1. **WHERE ARE WE?** — round / phase
2. **WHAT ARE WE DOING?** — purpose

# GOOGLE SLIDES TEMPLATE FRAMEWORK

Use the named Google Slides layouts below. **Prefer these layouts over creating new slide structures.**

| SLIDE | Purpose |
|---|---|
| `TITLE_CLASS` | Class opening. Include **Course Code + Lesson Code** (e.g. `MCF3M: M1C1`) in the top text box. Show the class join code. |
| `TEAM_INTRO` | “Meet Your Team” slide. |
| `OPEN_QUESTIONS_ROUND` | Round 1. Leave the main working area empty for the teacher to write/annotate examples live. |
| `TEAM_CHALLENGE_ROUND_CONTEXT` | Context/instructions the teacher presents before students begin team challenge work. |
| `TEAM_CHALLENGE_ROUND_QUESTION` | Main team challenge. Place the question in the designated text box. Include an image/diagram below when visualization is associated with the question. |
| `TEAM_CHALLENGE_REFLECTION` | Reflection / portfolio break. Include the required reflection questions. |
| `CONSOLIDATION_ROUND` | Final consolidation. Include question(s) connecting back to the lesson topic and learning. |

## BUILD RULES

- Preserve the template's typography, spacing, hierarchy, and brand colours.
- Embed tools, features, and questions in the appropriate format for the tash (plantext, markup, html, image snapshots) ensuring it is accurate and understandable on the slide
- enough to remain visually scannable during a live synchronous class.
- When teacher interaction is expected, **leave intentional whitespace** rather than filling the slide with content.
